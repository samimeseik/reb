# REB: هندسة عكسية لأي منشأة

### افهم كيف تعمل أي منشأة فعلاً: بالأدلة، ومع تسجيل ما بقي مجهولاً. للوكلاء الذكيين (MCP) وسطر الأوامر.

</div>

---

REB شقيق لمشروع [REA: Reverse Engineer Anything](https://github.com/morluto/rea)، الذي يفكك البرمجيات.
REB يطبّق الانضباط نفسه على **المصانع والورش والشركات والعيادات والوكالات، وأي منشأة**:
العمليات، والمكائن، والتوظيف، والموردون، والأنظمة، وتكلفة الوحدة، والمعرفة التي لا توجد إلا في رؤوس الناس.

المشكلة في تحليل الأعمال ليست صعوبة إنتاج قصة مقنعة. المستشارون ونماذج الذكاء الاصطناعي ينتجونها بسهولة مفرطة.
خريطة عمليات مخترعة تبدو مقنعة تماماً، بينما الكود المخترع على الأقل يفضح نفسه حين لا يعمل. REB موجود ليمنع ذلك:

- **كل ادعاء مربوط بدليل** له درجة من A إلى E. الدرجة تُحسب آلياً ولا يختارها المحلل.
- **ما لم يُغطَّ مجهول، وليس غير موجود.** كل فجوة تُسجَّل "مجهولاً" صريحاً، مع أرخص خطوة تحسمها.
- **المُعلَن مقابل الفعلي:** ما تقوله الوثائق والناس يُفصل عمّا تُظهره السجلات. والفجوة بينهما تُسجَّل تعارضاً ولا تُموَّه.
- **الاقتباسات تُفحص:** أي دليل يقتبس مصدراً يجب أن يطابق نصه حرفياً.
- **إعادة البناء لا تُغلق إلا بأدلة مسجّلة:** عنصر العملية أو إجراء التشغيل المعياري لا يصبح "جاهزاً" إلا إذا توفّر له: مالك مسؤول، ودليل مستقل لكل حالة مطلوبة، ونتيجة فحص مسجّلة كدليل من مصدر مستقل، ولا مجهول متناقض أو معطَّل في الطبقة نفسها. "جاهز" يعني أن السجل مكتمل، لا أن العملية ستنجح حتماً.
- **حدود النسخ:** كل نتيجة تُوسم بإحدى أربع فئات: قابل للتدوين، أو يحتاج قدرة، أو يحتاج أصلاً، أو غير قابل للنقل. الأخيرة تشمل العلاقات والرخص والموقع والتوقيت والمؤسس.

## ثلاثة أوضاع يفرضها المحرك نفسه

| الوضع | متى | ما المقبول |
|---|---|---|
| `self` | المنشأة ملكك أو تديرها | كل شيء، مع موافقة على المقابلات والمحادثات |
| `engaged` | عندك تفويض مكتوب منها (استشارة، أو فحص قبل الشراء بموافقتها) | كل شيء، مع موافقة على المقابلات والمحادثات |
| `public` | مصادر عامة فقط | السجلات والمؤشرات العامة. أما الوثائق الداخلية والتصديرات والمحادثات والمقابلات **فيرفضها المحرك** |

REB ليس أداة للحصول على أسرار منشأة أخرى. اقرأ [docs/LEGAL.md](docs/LEGAL.md).

## ماذا يقرأ

- المستندات النصية، وMarkdown، وWord، وPDF
- الصور والمسوحات ولوحات المكائن، عبر OCR بالعربية والتركية والإنجليزية
- ملفات Excel وCSV المصدّرة من الأنظمة
- **محادثات واتساب المصدّرة** (iOS وAndroid). أسماء المرسلين تُستبدل برموز مستعارة عند الإدخال
- **الفواتير الإلكترونية التركية (e-Fatura) بصيغة UBL**
- تسجيلات المقابلات، تُفرَّغ بـ whisper وتُعامل كشهادة
- الجولات الميدانية ودراسات الوقت، وتُعامل كملاحظة مباشرة

**والتحليلات:**
- **تعدين العمليات** من جدول أو من مجموعة واتساب: المسارات، والمخطط بصيغة Mermaid، ومدة الدورة، وإعادة العمل
- تركّز الإيراد والمشتريات
- المقارنة بين المُعلَن والفعلي
- التغطية عبر 11 طبقة
- دفتر الالتزامات
- **تقرير بالعربية (من اليمين لليسار) أو الإنجليزية**

## ملفات التشغيل: محرك واحد وأسئلة كثيرة

| الملف | الاستخدام |
|---|---|
| `sop-replication` | توثيق نظام تشغيل منشأتك لتوسيعها أو منحها امتيازاً أو تسليمها أو بيعها |
| `dd-evidence` | ملف أدلة قبل الشراء أو الشراكة، بموافقة المنشأة، وبدون أي تقييم مالي |
| `factory-capacity` | هل يستطيع المصنع إنتاج ما يدّعيه؟ |
| `hiring-system` | كيف تجد المنشأة الناس وتختارهم وتدرّبهم وتدفع لهم وتحتفظ بهم |
| `it-systems` | خريطة الأنظمة والبيانات وأماكن النقل اليدوي |
| `desk-scan` | مسح من المصادر العامة: ملاحظات وأسئلة فقط |

## البدء السريع

```bash
pip install "reb-agents[mcp,excel,pdf]"

mkdir my-workshop && cd my-workshop
reb init --name "توثيق الورشة" --subject "ورشتنا" --mode self \
         --authorization "المالك" --profile sop-replication --language ar
reb ingest ~/exports/orders.csv --custody subject_held --origin "مكتب الورشة"
reb coverage
reb report --lang ar --out report.md
```

مثال كامل لورشة أثاث افتراضية تجده في [examples/furniture-workshop](examples/furniture-workshop).
في هذا المثال يُظهر المحرك ثلاثة أشياء:
- أن الإجراء المكتوب يقول 10 أيام، بينما مجموعة الواتساب تُظهر وسيطاً قدره 14.9 يوماً
- أن كابينة الدهان هي عنق الزجاجة
- أن ضبط ماكينة الحواف يعتمد على شخص واحد

## مع وكيلك الذكي (MCP)

```bash
claude mcp add reb -e REB_WORKSPACE=/absolute/path/to/engagement -- reb mcp
```

ثم ثبّت المهارة الموجودة في [skills/reverse-engineer-business](skills/reverse-engineer-business) واطلب مثلاً:

```text
افتح ملفاً بوضع self لورشتي بملف التشغيل sop-replication، وأدخل الملفات الموجودة في ~/exports،
وارسم مسار الطلب حتى التسليم من مجموعة الواتساب، وأخبرني ما الذي ما زال مجهولاً.
```

## الخصوصية

- **محلي أولاً:** السجل محفوظ في `.reb/` داخل مساحة العمل، ومستثنى تلقائياً من git، ولا يُنسخ أي ملف أصلي.
- **الأسماء والهواتف والبريد والآيبان والأرقام الوطنية تُستبدل برموز** قبل تخزين النص، والجدول الذي يربط الرموز بالأسماء يبقى محلياً.
- إرسال البيانات لنموذج ذكاء اصطناعي مستضاف خارج البلد يُعدّ نقلاً عبر الحدود بحسب KVKK وGDPR وPDPL.
